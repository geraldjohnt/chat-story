# Pending outlines

Story proposals awaiting the user's explicit approval. One Markdown file per proposal:
`<YYYYMMDD>-<slug>.md`, based on `TEMPLATE.md`.

- `Status: pending` — waiting for review. Revisions edit the same file (note the revision date).
- `Status: approved → story <id>` — approved and generated; keep as a record.
- `Status: rejected` — keep briefly for originality checks, or delete when the user asks.

Nothing in this directory is published or deployed.
